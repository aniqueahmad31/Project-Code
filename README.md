# Online Shopping System (Java)

A console-based online shopping application built in Java to practice
Object-Oriented Programming concepts.

## Features
- Users can browse products and add them to a cart
- Order placing and bill generation
- Manager can handle inventory

## Classes
User, Manager, Product, Cart, Order, Bill, InventoryManager, OnlineShopApp (main)

## OOP Concepts Used
Classes and objects, inheritance, encapsulation, polymorphism

## How to Run
Compile all .java files and run OnlineShopApp.java
